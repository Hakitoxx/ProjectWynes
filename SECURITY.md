# Security Policy

## Scope

Project Wynes is **defensive diagnostic software**. It is designed for
authorized diagnostics of systems and networks you own or are explicitly
permitted to inspect.

## Reporting a vulnerability

Please report security issues (e.g., command injection possibilities,
installer weaknesses, data-handling mistakes) responsibly:

- Use GitHub's **"Report a vulnerability"** feature on the repository's
  Security tab (private by design), or open a minimal public issue that
  describes the *category* of the problem without exploit details until a
  fix is available.
- Do **not** include passwords, API keys, tokens, private keys, or other
  secrets in reports. Redact personal data.
- Do not publicly disclose details before a fix is released and users have
  had reasonable time to update.

## What to expect

- Acknowledgement of your report as soon as practical.
- A fix or a documented decision, and credit in the release notes if you like.

## Out of scope

- Issues requiring the attacker to already control the user's machine.
- Vulnerabilities in Nmap itself (report those to nmap.org).
